# Changelog

## [1.0.0] - 2026-10-23

### Added
- Network status panel with verdict engine, live trend graph, and data-driven tiles.
- Bufferbloat, public IP, battery, OS updates, CPU/memory, Wi-Fi, IPv6, and device addons.
- systemd user autostart bound to `sway-session.target`, with automatic restart.

### Fixed
- CPU tile shows usage instead of temperature.
- Disk usage reads the real home filesystem instead of a tiny composefs root.
- Bars and graph are measurement-driven; no idle/random animation.
